# StaySync Hotel Booking System

Hi, my name is George and this is my StaySync hotel booking website. I built it as a prototype system for managing hotel room reservations.

## What the website does

- Shows available rooms
- Lets a customer create a room booking
- Saves booking details in the browser
- Shows saved bookings in the Booking Desk
- Has a Staff Console where staff can view, edit, and remove bookings

## Files included

- index.html
- rooms.html
- booking.html
- manage.html
- admin.html
- script.js
- style.css
